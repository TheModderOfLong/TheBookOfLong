# CustomTkinter 专业版 EXE 打包工具设计方案

下面是基于 `CustomTkinter` 的专业版 GUI 改造方案。

---

# 总体设计方向

目标风格：

* Windows 11 / VSCode 风格
* 深色现代化 UI
* 卡片式布局
* 左右分栏
* 强调状态反馈
* 更强的专业感

技术栈：

```bash
pip install customtkinter
pip install tkinterdnd2
pip install pillow
```

其中：

* customtkinter：现代 UI
* tkinterdnd2：拖拽文件
* pillow：图标与图片支持

# 核心功能升级

# 1. 拖拽 Python 文件

支持：

* 拖入 .py
* 自动填充路径
* 自动识别项目
* 自动设置输出名

实现：

```python
from tkinterdnd2 import DND_FILES, TkinterDnD

root.drop_target_register(DND_FILES)
root.dnd_bind('<<Drop>>', self.on_drop)
```

拖入后：

```python
def on_drop(self, event):
    file_path = event.data.strip("{}")
```

---

# 2. 自动项目识别

拖入脚本后：

自动检测：

```text
requirements.txt
venv
.ico
.spec
```

示例：

```python
project_dir = os.path.dirname(script)

if os.path.exists(os.path.join(project_dir, 'requirements.txt')):
    self.add_detect('requirements.txt')
```

UI 显示：

```text
✅ 检测到 requirements.txt
✅ 检测到虚拟环境
⚠ 未发现图标文件
```

---

# 3. 实时命令预览

界面动态显示：

```bash
pyinstaller --onefile --noconsole --icon icon.ico main.py
```

用户每修改一个选项：

* 自动刷新命令
* 提升专业感
* 方便调试

建议使用：

```python
CTkTextbox
```

配 monospace 字体。

---

# 4. 打包进度动画

不建议假进度条乱跑。

推荐：

## 阶段式进度

```text
[10%] 初始化环境
[25%] 分析依赖
[50%] 收集模块
[75%] 生成 EXE
[100%] 完成
```

通过解析 PyInstaller 输出实现。

# 5. 状态图标系统

日志分级：

```text
✅ 成功
⚠ 警告
❌ 错误
ℹ 信息
```

示例：

```python
self.log('✅ 打包完成')
self.log('⚠ 未发现 requirements.txt')
self.log('❌ 打包失败')
```

日志颜色区分：

* 绿色：成功
* 黄色：警告
* 红色：错误
* 蓝色：信息

# 7. 卡片式布局

推荐：

```python

```

每个功能区域独立：

* 文件配置
* 打包选项
* 项目检测
* 日志
* 进度

视觉层次会非常明显。

# 8. 深色主题

推荐：

```python
ctk.set_appearance_mode("dark")
ctk.set_default_color_theme("blue")
```

或者：

```python
"dark-blue"
```

推荐配色：

| 元素  | 颜色      |
| --- | ------- |
| 背景  | #1e1f22 |
| 卡片  | #2b2d30 |
| 主按钮 | 蓝色      |
| 成功  | 绿色      |
| 警告  | 黄色      |
| 错误  | 红色      |

# 推荐附加功能

# A. 自动检测 PyInstaller

启动时：

```python
shutil.which("pyinstaller")
```

如果没有：

```text
❌ 未安装 PyInstaller
```

并提供：

```bash
pip install pyinstaller
```

---

# B. 一键安装依赖

检测到 requirements.txt：

```text
[安装项目依赖]
```

执行：

```bash
pip install -r requirements.txt
```

---

# C. 打包历史记录

保存最近项目：

```json
recent.json
```

下次启动：

```text
最近项目
- demo.py
- app.py
```

---

# D. 打包模板

例如：

```text
GUI应用

游戏程序
自动化脚本
```
