# 自定义剧情开发指南

> 本文档介绍如何通过 C# MOD 代码实现自定义剧情。  
> 适用于龙胤立志传 MOD 开发，基于 Il2CppInterop 框架。

---

## 一、两种实现方式对比

| | 方式一：CSV 定义 + C# 跳转 | 方式二：C# 代码完全构造 |
|---|---|---|
| **原理** | 剧情文本/选项写在 PlotData.csv，C# 负责条件判断后跳转 | 用代码构造 PlotData + SinglePlotData 对象 |
| **适用场景** | 固定文本剧情，条件分支 | 动态文本、运行时生成内容 |
| **复杂度** | 低 | 高 |
| **可维护性** | CSV 文本可视化编辑 | 需改代码重新编译 |
| **推荐度** | **优先推荐** | 仅在必要时使用 |

## 二、方式一：CSV 定义剧情 + C# 跳转（推荐）

### 2.1 PlotData.csv 格式

CSV 列定义如下：

| 列序号 | 列名 | 说明 | 示例 |
|--------|------|------|------|
| 1 | 剧情编号 | 剧情ID，首行为新剧情起始，空行表示接续上一条 | `1427` |
| 2 | 角色左 | 左侧角色标识 | `玩家`、`白云天`、`无` |
| 3 | 角色右 | 右侧角色标识 | `白云天`、`无` |
| 4 | 高亮方 | 高亮哪一侧：`左`/`右`/`无`/`皆` | `左` |
| 5 | 背景图片 | 背景图路径 | `PlotImage/泰岳大典` |
| 6 | 背景音乐 | BGM 路径 | `Fight1` |
| 7 | 播放音效 | 音效路径 | `SpeEffect/龙咆哮` |
| 8 | PlotShock | 是否震屏：`TRUE`/空 | `TRUE` |
| 9 | 调用函数 | 点击时调用的函数 | `ChangePlotDataBase;1427` |
| 10 | 选项 | 选项文本，用 `\|` 分隔 | `选项1\|选项2` |
| 11 | 内容 | 对话文本，支持 `\n` 换行 | `小白，你就是我婆娘~` |

### 2.2 调用函数写法

调用函数列支持以下常见写法：

| 写法 | 含义 |
|------|------|
| `ChangePlotDataBase;剧情ID` | 跳转到指定剧情 |
| `AddPlotDataBase;剧情ID` | 追加剧情到队列 |
| `FightStart;fight_001` | 触发战斗 |
| `SpePlotFuc;指令名*参数1#参数2` | 调用自定义特殊剧情指令 |
| `HideMemoryCover` | 隐藏回忆遮罩 |
| `SetHeroRecruitable;角色名` | 设置角色可招募 |
| `SetHeroLoveAble;角色名-true` | 设置角色可恋爱 |

多函数可用 `|` 连接：`SetHeroRecruitable;杨思迟|SetHeroLoveAble;杨思迟-true`

### 2.3 文本占位符

| 占位符 | 含义 |
|--------|------|
| `#PlayerName#` | 玩家名字 |
| `#TargetInteractName#` | 目标角色关系称呼 |
| `#SourceInteractName#` | 源角色关系称呼 |

### 2.4 CSV 示例

```csv
剧情编号,角色左,角色右,高亮方 右/左/无/皆,背景图片,背景音乐,播放音效,PlotShock,调用函数,选项,内容
1427,玩家,白云天,左,,,,,,,小白，我们来测试自定义函数吧。
,,,左,,,,,SpePlotFuc;IsPreLoverChangePlotDataBase*1428-1429,,试试条件判断！
1428,玩家,白云天,左,,,,,,,,,,小白，你就是我婆娘~
,,,右,,,,,,,#PlayerName#，不害臊！
```

### 2.5 C# 跳转代码

通过 Harmony Patch 拦截游戏逻辑，在满足条件时跳转到自定义剧情：

```csharp
using HarmonyLib;
using Il2Cpp;

namespace MyMod
{
    [HarmonyPatch(typeof(PlotController), "AskHeroToLover")]
    public static class MyPlotPatch
    {
        [HarmonyPrefix]
        public static bool Prefix(PlotController __instance)
        {
            HeroData source = __instance.sourceInteractHero;
            HeroData target = __instance.targetInteractHero;

            // 确保源角色是玩家
            HeroData player = GameController.Instance?.worldData?.Player();
            if (source != player) return true;

            // 特定角色跳转到自定义剧情
            if (target != null && target.heroID == 4)  // 白云天
            {
                __instance.ChangePlotDataBase(1427);    // 跳转到CSV中ID=1427的剧情
                return false;                           // 拦截原方法
            }

            return true;  // 其他角色走原版逻辑
        }
    }
}
```

### 2.6 PlotController 剧情跳转 API

| 方法 | 说明 |
|------|------|
| `ChangePlotDataBase(int plotId)` | 从数据库按 ID 切换剧情（替代当前剧情） |
| `ChangePlotDataBase(string plotId)` | 从数据库按字符串 ID 切换剧情 |
| `AddPlotDataBase(int plotId)` | 从数据库追加剧情到队列（当前剧情播完后继续） |
| `AddPlotDataBase(string plotId)` | 同上，字符串 ID |
| `ChangePlot(PlotData plot)` | 切换到 PlotData 对象 |
| `ChangePlot(SinglePlotData singlePlot)` | 切换到单句对白 |
| `AddPlot(PlotData plot)` | 追加 PlotData 到队列 |
| `AddPlot(SinglePlotData singlePlot)` | 追加单句对白到队列 |
| `AddPlot(SinglePlotData singlePlot, int index)` | 在指定位置插入对白 |

## 三、方式二：C# 代码完全构造剧情

当剧情文本需要根据运行时状态动态生成时，可直接用代码构造 `PlotData` + `SinglePlotData`。

### 3.1 核心数据类

#### PlotData（一组对话的容器）

| 字段 | 类型 | 说明 |
|------|------|------|
| `plotID` | int | 剧情编号 |
| `plotName` | string | 剧情名称 |
| `spePlot` | bool | 是否特殊剧情 |
| `plotDatas` | `List<SinglePlotData>` | 对话列表（核心字段） |
| `plotCallFuc` | string | 剧情整体调用函数 |
| `targetHeroID` | int | 目标角色 int ID |
| `differentForce` | bool | 是否不同势力 |
| `randomStartPlot` | bool | 是否随机起始剧情 |
| `plotRandomHero` | `List<PlotRandomHeroData>` | 随机角色数据 |

#### SinglePlotData（单条对话）

| 字段 | 类型 | 说明 |
|------|------|------|
| `plotText` | string | 对话原始文本（含占位符） |
| `plotSource` | PlotTargetHeroType | 源角色定位方式 |
| `sourceName` | string | 源角色名 |
| `plotTarget` | PlotTargetHeroType | 目标角色定位方式 |
| `targetName` | string | 目标角色名 |
| `hightLightType` | HeroFaceHightLightType | 高亮方 |
| `clickCallFuc` | string | 点击回调函数 |
| `noAutoJump` | bool | 是否禁止自动跳转（有选项时必须为 true） |
| `backPic` | string | 背景图路径 |
| `backBgm` | string | 背景音乐路径 |
| `soundEffect` | string | 音效路径 |
| `plotShock` | bool | 是否震屏 |

### 3.2 枚举类型

#### PlotTargetHeroType（角色定位方式）

| 枚举值 | 序号 | 含义 |
|--------|------|------|
| `Keep` | 0 | 保持上一句的角色 |
| `None` | 1 | 无角色 |
| `Pic` | 2 | 仅显示立绘 |
| `HeroID` | 3 | 按 int ID 指定角色 |
| `PlotInteractHero` | 4 | 使用剧情交互角色 |
| `HeroName` | 5 | 按角色名指定 |
| `MissionEventTargetHero` | 6 | 任务事件目标角色 |
| `MissionEventSourceHero` | 7 | 任务事件源角色 |
| `ChosenHero` | 8 | 角色选择器选中的角色 |

#### HeroFaceHightLightType（高亮方）

| 枚举值 | 序号 | 含义 |
|--------|------|------|
| `Right` | 0 | 右侧高亮（右侧角色说话） |
| `Left` | 1 | 左侧高亮（左侧角色说话） |
| `All` | 2 | 两侧高亮 |
| `None` | 3 | 无高亮 |

> **注意**：CSV 中的"高亮方"写法（`左`/`右`/`无`/`皆`）与枚举的对应关系为：`左`→Left，`右`→Right，`无`→None，`皆`→All。

### 3.3 SinglePlotData 构造函数

```csharp
// 常用构造函数（最完整版本，CallerCount=59）
new SinglePlotData(
    string targetPlotText,           // 对话文本
    List<string> choiceDataTexts,    // 选项列表（null为无选项）
    PlotTargetHeroType targetHeroType, // 目标角色定位
    string targetHeroName,           // 目标角色名
    PlotTargetHeroType sourceHeroType, // 源角色定位
    string sourceHeroName,           // 源角色名
    HeroFaceHightLightType hightLightType, // 高亮方
    string _clickCallFuc,            // 点击回调函数
    bool _noAutoJump,                // 禁止自动跳转（有选项时必须true）
    string _backPic = null,          // 背景图（null保持上一句）
    string _backBgm = null,          // 背景音乐（null保持上一句）
    string _soundEffect = null,      // 音效
    bool _plotShock = false          // 震屏
)
```

> **重要**：`List<string>` 必须使用 `Il2CppSystem.Collections.Generic.List<string>`，不是 `System.Collections.Generic.List<string>`。

### 3.4 选项文本格式

选项列表中每个元素的格式：

```
选项显示文本|点击回调函数|参数|描述
```

| 示例 | 含义 |
|------|------|
| `"拔剑迎敌\|FightStart;fight_001\|\|"` | 选项文本"拔剑迎敌"，触发战斗 |
| `"转身逃跑\|ChangePlotDataBase;99998\|\|"` | 跳转到剧情99998 |
| `"大声呼救\|SpePlotFuc;CheckConditionChangePlotDataBase*... \|\|"` | 调用复合条件指令 |

### 3.5 完整代码示例

```csharp
using Il2Cpp;
using Il2CppSystem.Collections.Generic;  // 注意：Il2Cpp 的 List

public static class MyPlotBuilder
{
    /// <summary>
    /// 构造并播放一段3句对话的自定义剧情
    /// </summary>
    public static void PlayMyCustomPlot(PlotController pc)
    {
        // 1. 创建 PlotData 容器
        var plotData = new PlotData();
        plotData.plotID = 99999;
        plotData.plotName = "我的自定义剧情";

        // 2. 创建对话列表
        var singlePlots = new List<SinglePlotData>();

        // --- 第1句：旁白（无角色） ---
        var line1 = new SinglePlotData(
            targetPlotText: "夜深了，洛阳城外传来一阵马蹄声。",
            choiceDataTexts: null,
            targetHeroType: PlotTargetHeroType.None,
            targetHeroName: "",
            sourceHeroType: PlotTargetHeroType.None,
            sourceHeroName: "",
            hightLightType: HeroFaceHightLightType.None,
            _clickCallFuc: "",
            _noAutoJump: false,
            _backPic: "PlotImage/洛阳城外",
            _backBgm: "BGM/Suspense",
            _soundEffect: "",
            _plotShock: false
        );
        singlePlots.Add(line1);

        // --- 第2句：玩家说话（左侧高亮） ---
        var line2 = new SinglePlotData(
            targetPlotText: "什么人？！",
            choiceDataTexts: null,
            targetHeroType: PlotTargetHeroType.HeroName,
            targetHeroName: "白云天",
            sourceHeroType: PlotTargetHeroType.HeroName,
            sourceHeroName: "玩家",
            hightLightType: HeroFaceHightLightType.Left,
            _clickCallFuc: "",
            _noAutoJump: false,
            _backPic: null,    // null = 保持上一句背景
            _backBgm: null,    // null = 保持上一句音乐
            _soundEffect: null,
            _plotShock: false
        );
        singlePlots.Add(line2);

        // --- 第3句：带选项的对话 ---
        var choices = new List<string>();
        choices.Add("拔剑迎敌|FightStart;fight_001||");
        choices.Add("转身逃跑|ChangePlotDataBase;99998||");
        choices.Add("大声呼救|SpePlotFuc;CheckConditionChangePlotDataBase*[$HeroData:favor:白云天$][>]50#99997-99998||");

        var line3 = new SinglePlotData(
            targetPlotText: "来者不善，你要怎么做？",
            choiceDataTexts: choices,
            targetHeroType: PlotTargetHeroType.Keep,  // 保持上一句角色
            targetHeroName: "",
            sourceHeroType: PlotTargetHeroType.Keep,
            sourceHeroName: "",
            hightLightType: HeroFaceHightLightType.None,
            _clickCallFuc: "",
            _noAutoJump: true,   // 有选项时必须禁止自动跳转
            _backPic: null,
            _backBgm: null,
            _soundEffect: null,
            _plotShock: true     // 震屏特效
        );
        singlePlots.Add(line3);

        // 3. 将对话列表赋给 PlotData
        plotData.plotDatas = singlePlots;

        // 4. 播放剧情
        pc.AddPlot(plotData);          // 追加到队列（当前剧情播完后播放）
        // 或 pc.ChangePlot(plotData);  // 直接切换（立即播放）
    }
}
```

### 3.6 从 SpePlotFuc 自定义指令中触发

在 `SpePlotFucPatches` 的指令处理器中触发剧情，是更常见的做法：

```csharp
// 1. 注册到 FucHandlers 字典
{ "MyCustomPlot", TryCallFucMyCustomPlot },

// 2. 处理函数
private static void TryCallFucMyCustomPlot(PlotController __instance, string fucName, string[] fucParams)
{
    // 格式: SpePlotFuc;MyCustomPlot*参数1#参数2
    string param1 = fucParams.Length > 0 ? fucParams[0] : "";

    // 方式A：跳转到CSV中定义的剧情（推荐）
    __instance.ChangePlotDataBase(99999);

    // 方式B：代码动态构造剧情后播放
    // MyPlotBuilder.PlayMyCustomPlot(__instance);
}
```

CSV 中调用方式：`SpePlotFuc;MyCustomPlot*参数1`

## 六、注意事项

1. **Il2Cpp List**：构造 `SinglePlotData` 的选项列表时，必须用 `Il2CppSystem.Collections.Generic.List<string>`，不能用 `System.Collections.Generic.List<string>`
2. **null 保持不变**：`_backPic`、`_backBgm`、`_soundEffect` 传 `null` 表示保持上一句的设置，传空字符串 `""` 可能会清除
3. **选项与 noAutoJump**：有选项的对话**必须**设置 `_noAutoJump = true`，否则选项来不及显示就跳到下一句
4. **HarmonyPrefix 返回值**：`return false` 拦截原方法，`return true` 放行原方法
5. **剧情ID 分配**：自定义剧情建议使用高位 ID（如 10000+），避免与官方 ID 冲突
6. **CSV 编码**：PlotData.csv 使用 UTF-8 编码
7. **占位符替换**：`#PlayerName#` 等占位符在剧情显示时替换，构造 SinglePlotData 时写原始占位符即可
8. **选项分隔符**：选项内部用 `|` 分隔，选项之间用列表元素分隔
